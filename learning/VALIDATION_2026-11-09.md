# 2026-11-09 변경 검증

기존 `VALIDATION.md`, `SOURCE_SNAPSHOT.json`, `SHA256SUMS.txt`는10월29일 당시 기록이다.
이번 변경의 출처와 파일 해시는 `SOURCE_UPDATE_2026-11-09.json`에 별도로 기록한다.

## STM32

- encoder_basic과 encorder_test를 ARM GCC로 컴파일·링크 완료했다.
- 두 프로젝트의 현재 윤거는234mm, 명목 둘레345.6mm, 임시 CPR은 모터1 2475.6 / 모터2 2465.2다.
- encorder_test는 UART 없이 같은 제어 로직을 main.c에 포함한다. 기존 미완성 모듈은 보존하고 빌드에서 제외했다.
- 디버깅 버전 생성 시 실제 제어 루프의 HAL 모의 실행으로2초간 명령 유지, 0 명령의 PI·PWM 초기화,
  16/32비트 카운터 순환을 검사했다. 이후 변경은 치수·CPR 상수이며 최종 ARM 빌드를 다시 확인했다.
- 이번 저장소 업데이트에서 보드 다운로드·실제 모터 구동·새 CPR 실측은 하지 않았다.

## ROS 및 설정

- 브릿지의 윤거 상수를0.234m로 맞췄다. UART 규약과 나머지 동작은 유지했다.
- URDF 구동축 y 좌표만±0.117m로 맞추고 저장소의 기존 라이다 yaw=π를 보존했다.
- 최신 저장소의 bringup, scan_reader, 11월6일 실측 기록을 유지했다.
- Python 파일 9개의 AST, XML, Bash 구문, 최종 치수와 19개 소스 파일의 해시 일치를 확인했다. 현재 변경에 대한 전체 ROS 재빌드·실물 재검증은 별도다.
- WSL 통신의1400바이트 대조 및 실제 셧다운2회 검증은11월7일 조사 결과이며11월9일에 새로 수행한 시험이 아니다.
- Jetson 파일은 이번 PC 변경으로 자동 수정되지 않는다. 브릿지 윤거를0.234m로 별도 적용해야 한다.
