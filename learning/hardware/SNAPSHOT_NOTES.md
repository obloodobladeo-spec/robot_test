# 원본 하드웨어 기록 이후 보충

기준2026-10-29. README.md는 원본의2026-10-23 기록 그대로이며 아래는 최근 대화에서 확인한 내용입니다.

- STM32F446RE, MDD10A, 모터2개, Jetson Orin Nano8GB, C1 보유. 외장 IMU 보유 기록은 없습니다.
- 구동은 후륜2모터. base_link는 좌우 구동축 중간점.
- 차체250×180×56.4mm, 후륜축은 뒤 끝에서17mm 앞. 축 기준 차체 중심x=108mm.
- 타이어 지름110mm·폭45mm, 윤거230mm. 앞 보조 바퀴 위치는 임시 모델 값이며 실측 확정이 아닙니다.
- 라이다 회전 중심은 차체 앞 끝 가운데에서 뒤로83mm. 받침 지름116mm·높이30mm.
- C1 측정면은 바닥에서29.8mm. 현재 모델에서 base_link→laser=[0.150,0,0.088]m. 지면 기준 C1 바닥113.2mm, 측정면143.0mm로 계산.
- 실제 C1의 ROS2 scan은 약10Hz·720개 거리값을 확인했습니다. 수신 성공과 실제 장착 자세 검증은 다릅니다.
- Jetson Humble과 ~/ros2_ws에서 STM32 USB 정지 피드백·odom·TF 확인 기록이 있습니다. 현재 실시간 상태를 보장하지 않습니다.
- BUSID·COM 번호는 고정값이 아닙니다. 이번에는 CP210x COM5 / BUSID1-4 / WSL ttyUSB0을 사용했습니다.
- 종료 후 회전이 남아 USB를 복구하고 제조사 드라이버의 Stop motor·종료코드0을 확인했으며, 사용자가 실제 정지를 확인했습니다.
