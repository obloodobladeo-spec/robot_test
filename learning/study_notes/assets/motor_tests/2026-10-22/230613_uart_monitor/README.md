# UART 송신 상태와 정지 상태 모니터링

- 모터 명령·이득·펌웨어를 변경하지 않고 약 25초 동안 SWD로 상태를 읽었습니다. 보드의 코드·초기 데이터가 현재 ELF와 일치하는 것을 확인했습니다.
- 관측 표본에서 차체 속도 명령, 양쪽 모터 속도·목표·듀티·CCR, 구간 이동량, 누적 x·y·yaw는 모두 0으로 유지됐습니다. 정지 중 위치가 계속 증가하는 현상은 이번 구간에서 관측되지 않았습니다.
- 송신 버퍼는 `L=0 R=0  X=0 Y=0\r\n`, 송신 요청 상태는 HAL_OK(0)였습니다. busy는 모든 관측 표본에서 0이었으며, 짧은 송신 구간은 표본 사이에 발생할 수 있으므로 표본만으로 완료 콜백 횟수나 송신 주기를 검증하지는 않았습니다.
- COM11 직접 열기는 접근 거부로 실패했습니다. 다른 프로그램에서 사용하는 상황과 부합하므로 시리얼 모니터를 닫도록 요청했습니다. 직접 수신한 줄은 0개이며, 컴퓨터 수신 주기·내용의 최종 검증은 남아 있습니다.
- 원시 기록: `measurements.json`.
