# 바퀴를 띄운 상태의 PI·구간 오도메트리 디버깅

## 시험 조건과 실행

- 사용자가 바퀴를 띄웠다고 확인한 조건입니다. 실제 바닥 주행이나 접지 상태의 조정 결과로 해석하지 않습니다.
- Kp·Ki 조합: (0.1, 0.1), (0.05, 0.1), (0.2, 0.1), (0.1, 0.2), (0.1, 0.3). 한 계수씩 변경했습니다.
- 각 조합에서 직진 50mm/s, 회전 +0.3rad/s, 회전 -0.3rad/s를 각각 20초씩 적용했습니다. 완료 시험은 총 15회, 명령 적용 시간 합계는 300초입니다. 단계 사이에는 정지 확인했습니다.
- 가속도 제한 100mm/s², 듀티 상한 50%, 코드상 윤거 230mm를 유지했습니다. 차체 축소 후 실측 윤거는 아직 확인하지 않았습니다.
- 보드 플래시의 코드·초기 데이터와 현재 ELF를 비교한 뒤, 새 Motor 구조체 크기 88바이트와 오프셋을 확인했습니다. RAM의 이득과 차체 명령만 변경했으며 학습용 C 파일 수정·펌웨어 다운로드는 하지 않았습니다.
- SWD HOTPLUG로 속도, 구간 이동 거리, 구간 회전각, 적분, 듀티, 실제 CCR을 읽었습니다. 기존 100ms 제어 주기는 변경하지 않았습니다.
- 기본값 시험 원시는 [앞선 실행 기록](../014900_odom_gains/measurements.json)에, 나머지 네 조합은 이 폴더의 `measurements.json`에 있습니다.
- 첫 Kp=0.05 시작 직후, 측정 도구가 100ms 제어 주기에서 명령이 반영되기 전의 표본을 이상 상태로 판정해 정지했습니다. 그 1표본은 비교에서 제외했습니다. 명령 반영 대기 구간을 구분하도록 도구를 수정하고 정지·원래 이득 복구 확인 후 나머지를 재실행했습니다.

## 초기 응답 비교

목표 방향 속도가 목표 크기의 90% 이상인 표본이 3회 연속 관측된 구간의 첫 시각입니다. 완전한 정착 시간은 아니며, 양쪽 모터와 양방향 회전의 범위로 표시했습니다. 명령 시작부터의 시간으로 방향 전환 대기도 포함합니다.

| Kp | Ki | 직진 90% 도달 관측 | 양방향 회전 90% 도달 관측 |
|---|---|---|---|
| 0.1 | 0.1 | 4.70~5.00초 | 5.00~5.84초 |
| 0.05 | 0.1 | 4.16초 | 4.06~4.72초 |
| 0.2 | 0.1 | 5.62~6.95초 | 6.03~7.53초 |
| 0.1 | 0.2 | 2.86초 | 2.59~2.88초 |
| 0.1 | 0.3 | 2.00초 | 2.30~2.44초 |

- 이번 조건에서는 Ki 증가 시 초기 오차가 줄고 목표 부근에 더 빨리 도달했습니다.
- Kp=0.2의 최초 5초 평균 절대 오차는 기본값보다 작았지만, 위의 연속 90% 기준 도달은 늦었습니다. 초기 응답과 목표 부근 정착을 같은 지표로 판단하지 않습니다.
- 각 조건 1회이며 시험 순서를 섞지 않았습니다. 보편적인 최적 이득을 확정하는 결과는 아닙니다.

## 구간 오도메트리·출력 확인

- 기본값 직진의 후반 평균: `delta_s_mm=4.97448`, `delta_yaw_rad=0.000303`. 100ms에 약 5mm라는 기대와 일치합니다.
- 기본값 +회전: `delta_s_mm=-0.01549`, `delta_yaw_rad=0.029983`. -회전: `delta_s_mm=-0.01745`, `delta_yaw_rad=-0.029911`. 100ms에 약 ±0.03rad라는 기대와 일치합니다.
- 모든 완료 시험에서 좌우 이동량으로 다시 계산한 차체 이동 거리·회전각과 측정한 차체 변수의 차이 중앙값은 부동소수점 오차 수준이었습니다.
- SWD는 MCU를 멈추지 않고 순차 읽기하므로 일부 표본은 제어 주기를 걸쳐 읽힐 수 있습니다. 단일 표본의 변수 불일치를 바로 계산 오류로 판단하지 않습니다.
- 기본값 직진의 평균 듀티는 왼쪽 7.79%·오른쪽 7.18%, 평균 CCR은 약 326·301이었습니다. 회전은 약 5.6~6.0%·CCR 237~253이었습니다. 이는 공중 부하 조건의 값입니다.
- 이번 디버깅으로 이동량 계산의 실행은 확인했지만, 실제 차체 위치나 회전각·미끄러짐 오차는 검증하지 않았습니다. 누적 x·y·yaw도 아직 구현하지 않았습니다.

## 종료와 다음 판단

- 양쪽 Kp=0.1·Ki=0.1로 복구하고 읽어서 확인했습니다.
- 차체 명령, 양쪽 목표·실제 속도·구간 이동량·적분·듀티·CCR과 차체 구간 이동량·회전각 모두 0을 확인했습니다.
- 빠른 초기 응답 후보는 Kp=0.1·Ki=0.2~0.3입니다. 후반 변동이 모든 경우에서 줄지는 않아 최종 이득으로 저장하지 않았습니다.
