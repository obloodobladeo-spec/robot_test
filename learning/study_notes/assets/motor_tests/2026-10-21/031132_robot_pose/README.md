- 사용자 확인: 바퀴를 띄운 상태입니다. 직진 50mm/s·회전 명령 0을 10초 적용한 뒤 정지했습니다. Kp=0.1·Ki=0.1은 유지했습니다.
- 보드와 ELF의 코드·초기 데이터 일치, Motor 88바이트 배치와 Robot 32바이트 배치를 확인했습니다. RobotState 필드 주소는 현재 ELF의 디버그 정보에서 조회해 사용했습니다.
- 위치를 초기화하지 않고 기존 누적 상태를 유지했습니다. 펌웨어 수정·다운로드는 하지 않았습니다.

- 이번 방향 변화는 코드상 윤거 230mm에서 오른쪽 누적 이동량이 왼쪽보다 약 13.79mm 작은 것에 해당합니다. 시작 후 약 2초의 표본에서 왼쪽 32.24mm/s·오른쪽 22.34mm/s, 약 3초에서 39.25·26.52mm/s로 초기 좌우 응답 차이를 관측했습니다.
- 마지막 3초 관측 표본의 평균 속도는 왼쪽 49.59mm/s·오른쪽 55.49mm/s입니다. SWD는 100ms 제어값 모두를 연속 기록하지 않으므로 이 구간 표본 평균으로 전체 누적 회전 방향을 추론하지 않습니다. 실제 속도 변화와 표본 누락·주기 걸침 가능성을 구분합니다.
- `yaw_rad += delta_yaw_rad` 누적과 중간 방향을 사용한 x·y 계산 순서는 정상입니다. 모듈 분리로 부호가 뒤집히는 코드 변경은 확인되지 않았습니다.
- 정지 후 6개 추가 표본에서 x·y·yaw는 동일하게 유지됐습니다. 차체 명령과 양쪽 목표·측정 속도·이동량·적분·듀티·CCR, 차체 구간 이동량·회전각 모두 0을 확인했습니다.
- 공중 바퀴의 엔코더 차이에 따른 위치 추정 확인이며 실제 차체 회전이나 바닥 직진 정확도 검증은 아닙니다.
