# 누적 위치와 직진 중 y 증가 확인

- 조건: 사용자가 마지막으로 확인한 바퀴 공중 상태. Kp=0.1·Ki=0.1 유지, 직진 50mm/s·회전 명령 0을 10초 적용했습니다.
- 보드와 현재 ELF의 코드·초기 데이터 일치 및 Motor 구조체 배치를 확인했습니다. 위치를 초기화하지 않고 기존 누적 상태를 유지했습니다. C 파일 수정·펌웨어 다운로드는 하지 않았습니다.

| 변수 | 시험 전 정지 | 종료 후 정지 | 변화량 |
|---|---|---|---|
| x_mm | 1292.057 | 1714.219 | +422.162mm |
| y_mm | 15.222 | 24.876 | +9.655mm |
| yaw_rad | 0.014668 | 0.025794 | +0.011126rad |

- 시작 추정 방향은 약 +0.84°, 종료 방향은 약 +1.48°였습니다. 실제 차체 자세를 측정한 값은 아닙니다.
- 위치 변화 벡터의 방향은 약 +1.31°로, 이번 시험에서 y가 증가한 것은 양수로 누적된 방향을 따라 이동 거리를 x·y에 나눈 결과와 부합합니다. 회전 명령 0이 기존 yaw를 0으로 초기화하지는 않습니다.
- 양쪽 엔코더 이동량 차이로 yaw가 시험 중 약 +0.64° 추가 누적됐습니다. 공중 조건이므로 이를 실제 차체 회전이나 물리적 직진 편차로 단정하지 않습니다.
- 마지막 3초 평균 속도는 왼쪽 49.63mm/s, 오른쪽 49.56mm/s였습니다. 시험 전체의 누적 속도 차이와 마지막 구간 평균 차이는 구분합니다.
- 출발 가속과 PI 응답을 포함하므로 10초 명령의 추정 이동 거리가 500mm보다 작은 것은 곧바로 오도메트리 계산 오류를 뜻하지 않습니다.
- 정지 확인 뒤 6개 추가 표본에서 x·y·yaw는 모두 동일하게 유지됐습니다. 차체 명령, 양쪽 목표·속도·구간 이동량·적분·듀티·CCR, 차체 구간 이동량·회전각도 0을 확인했습니다.
- 현재 코드의 `yaw_rad += delta_yaw_rad` 누적과 x·y 투영 순서는 정상입니다. 다만 SWD 순차 표본과 코드 검토를 통한 기능 확인이며 실제 위치 정확도 검증은 아닙니다.
- 원시 데이터: `measurements.json`.
