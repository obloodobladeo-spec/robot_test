# 양방향 회전 각 10초 시험

- 사용자 요청으로 전진 0, 회전 +0.3과 -0.3rad/s를 각각 10초 측정했습니다. 방향마다 정지했습니다.
- 좌우 목표 속도는 +0.3에서 -34.5/+34.5mm/s, -0.3에서 +34.5/-34.5mm/s입니다.
- 후륜 구동, 모터1=왼쪽·모터2=오른쪽, 앞 보조 바퀴 전체 접촉면에 테이프를 적용한 사용자 설명 기준입니다. 실제 접지 조건은 직접 관측하지 않았습니다.
- Kp=0.1, Ki=0.1, 가속도 제한 100mm/s², 듀티 상한 50%를 유지했습니다. 실행 코드와 초기 데이터가 현재 ELF와 일치함을 확인했고 펌웨어는 변경하지 않았습니다.

## 확인 범위

- 이번 10초 안에서는 양방향 모두 목표 속도 크기 34.5mm/s에 도달하지 못했습니다. +0.3에서는 특히 왼쪽 회전이 거의 관측되지 않았습니다.
- 마지막 구간에도 적분 출력과 듀티가 증가하고 있어 출발 과정과 부하 영향을 구분해야 합니다. 이 결과를 정상상태 회전 성능이나 특정 모터 고장으로 단정하지 않습니다.
- 과거 20초 시험과 측정 시간이 다르고 접지 조건도 통제되지 않았으므로 단순한 성능 전후 비교로 해석하지 않습니다.
- 시험 후 전진·회전 명령과 양쪽 모터 목표·적용 목표·실제 속도·적분·듀티·CCR이 모두 0임을 확인했습니다.
