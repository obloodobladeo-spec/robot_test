# 전후진 ±50·±100mm/s, 각 10초

- 사용자 요청으로 +50 → -50 → +100 → -100mm/s를 각각 10초 측정했습니다. 회전 명령은 0이며 각 단계 후 정지했습니다.
- 앞 보조 바퀴 접촉면 전체에 절연테이프를 적용한 상태를 기준으로 했습니다. 접지 위치와 실제 이동 궤적은 직접 관측하지 않았습니다.
- Kp=0.1, Ki=0.1, 가속도 제한 100mm/s², 듀티 상한 50%를 유지했습니다. 실행 코드와 초기 데이터가 현재 ELF와 일치함을 확인했습니다. 펌웨어는 변경하지 않았습니다.
- 아래는 각 시험 마지막 2초 조회 표본의 평균입니다. 속도 단위는 mm/s입니다.

## 확인 범위

- ±50에서는 좌우 속도가 유사했지만 이번 10초 안에 목표에 도달하지 않았습니다.
- +100에서는 왼쪽 평균 속도가 더 낮고 필요한 듀티가 더 높았습니다. 외부 부하와 하중·마찰 등 물리 조건을 확인하기 전까지 모터 자체 문제라고 확정하지 않습니다.
- -100에서는 양쪽 평균 속도가 목표를 약 4mm/s 초과했습니다.
- 직전 8초 시험과 출발 위치·부하가 통제되지 않았으므로 결과 차이를 시간 증가만의 효과로 해석하지 않습니다. 정상상태 수렴과 실제 헛돎·옆 미끄러짐도 확인하지 않았습니다.
- 매 단계 후 차체 명령과 두 모터의 목표·적용 목표·실제 속도·적분·듀티·CCR이 모두 0임을 확인했습니다.
