# 전후진 ±50·±100mm/s, 각 8초

- 사용자 요청으로 +50 → -50 → +100 → -100mm/s를 순서대로 각각 8초 측정하고 단계마다 정지했습니다.
- 회전 명령 0, 후륜 구동, 모터1=왼쪽·모터2=오른쪽, 앞 보조 바퀴 접촉면 전체에 절연테이프 적용 상태입니다.
- Kp=0.1, Ki=0.1, 적용 목표 변화율 제한 100mm/s², 듀티 상한 50%를 유지했습니다. 보드 실행 코드와 초기 데이터가 현재 ELF와 일치함을 확인했습니다.
- 아래는 각 시험 마지막 2초 조회 표본의 평균입니다. 속도 단위는 mm/s입니다.

## 확인 범위

- ±50과 -100에서는 마지막 2초 평균의 좌우 속도가 비교적 가까웠습니다. 순간적인 속도 변동은 남아 있습니다.
- +100에서는 이번 8초 안에 양쪽 실제 속도가 목표에 못 미쳤고, 왼쪽이 더 높은 듀티를 사용했습니다. 장애물 접촉·케이블 당김 등 당시 접지 조건을 확인하기 전까지 모터 자체의 성능 차이로 단정하지 않습니다.
- 이 기록은 짧은 출발 시험이며 정상상태 수렴을 검증한 결과는 아닙니다. 실제 차체 이동 거리와 헛돎 여부는 별도로 관찰해야 합니다.
- 각 단계 후 차체 전진·회전 명령과 양쪽 모터의 목표·적용 목표·실제 속도·적분·듀티·CCR이 모두 0임을 확인했습니다.
