# 차체 회전 명령 ±0.3rad/s 비교

- 배치: 후륜 구동, 모터1=왼쪽, 모터2=오른쪽, 윤거 230mm.
- 전진 명령 0mm/s, 회전 명령 +0.3 또는 -0.3rad/s. 각 20초 측정했습니다.
- 사용자 관찰: 오른쪽 앞바퀴를 축으로 회전하는 것처럼 보였으며, 낮은 초기 듀티에서는 접지·마찰 때문에 반응이 늦다고 설명했습니다.
- 물리적인 회전 중심과 앞바퀴 구조는 도구로 직접 관찰하지 않았습니다. 앞바퀴의 고정·캐스터 여부는 아직 미확인입니다.
- Kp=0.1, Ki=0.1, 적용 목표 변화율 제한 100mm/s², 제어 간격 100ms, PWM 20kHz, 듀티 상한 50%.
- 보드 실행 코드와 초기 데이터가 최신 ELF와 일치하는 것을 확인했습니다. 학습 코드·게인·듀티 제한은 변경하지 않았습니다.

## 출발 관측

+0.3 시험에서는 속도 크기가 5mm/s 이상인 첫 표본이 왼쪽 약 8.17초·듀티 29.57%, 오른쪽 약 6.39초·듀티 23.40%에서 관측됐습니다. 이 시각은 첫 엔코더 회전 표본이며 자력 구동 시작을 직접 검출한 시각은 아닙니다.

직전 8초 시험의 마지막 2초 평균은 왼쪽 -1.17mm/s, 오른쪽 +15.59mm/s였습니다. 듀티가 충분히 누적되기 전의 초기 상태였으므로 이를 정상상태 성능으로 판단하지 않습니다.

## 해석과 제한

- 차체 명령에서 좌우 바퀴 목표로의 변환은 예상대로 ±34.5mm/s였습니다.
- 회전 부하에서 듀티가 약 30% 수준까지 증가한 뒤 움직임이 나타났습니다. 초기 저속만으로 모터 고장이나 구동 한계를 확정할 수 없습니다.
- 반대 방향에서도 이번 20초 관측 안에서는 왼쪽이 더 높은 듀티를 사용하면서 목표에 덜 도달했습니다. 좌우 속도 차이와 시간 변동이 남아 있으며 정상상태 수렴을 확인한 결과가 아닙니다.
- 엔코더 기록만으로 오른쪽 앞바퀴가 회전 중심이 된 정확한 이유를 확정할 수 없습니다. 고정 보조 바퀴의 옆 미끄러짐 저항, 하중, 구동 방향별 저항, 휠·허브 결합과 실제 접지 운동을 추가로 구분해야 합니다.
- 시험 종료 때 차체 전진·회전 명령을 모두 0으로 내렸고 두 모터의 목표·적용 목표·실제 속도·적분·듀티·CCR=0을 확인했습니다. 모터 목표만 0으로 쓰면 메인의 차체 명령이 재적용되므로 정지는 차체 명령에서 수행했습니다.
