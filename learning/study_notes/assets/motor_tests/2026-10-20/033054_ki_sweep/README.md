# 하중 추가 상태의 회전 Ki 비교

## 조건

- 사용자가 추가 하중을 올렸다고 확인했습니다. 질량·배치 위치는 미측정입니다. 앞 보조 바퀴 접촉면에는 절연테이프가 적용되어 있습니다.
- Kp=0.1 유지, Ki=0.1·0.2·0.3 순서로 RAM에서 변경했습니다. 각 값에서 회전 +0.3rad/s, -0.3rad/s를 각각 20초 적용했습니다.
- 전진 명령 0, 윤거 230mm, 좌우 목표 속도 크기 34.5mm/s, 가속도 제한 100mm/s², 듀티 상한 50%입니다.
- 각 시험 전후 정지 확인, 보드와 ELF의 코드·초기 데이터 일치 확인, 이득 변경 후 읽기 확인을 수행했습니다. 펌웨어 파일 수정·다운로드는 하지 않았습니다.
- 앞서 진행한 10초 비교는 시간 연장 요청으로 중단했습니다. 해당 부분 기록은 `../033008_ki_sweep/comparison.json`에 있으며 아래 비교에는 포함하지 않습니다.

## 해석과 종료 상태

- 이번 순차 시험에서는 Ki가 클수록 지속 회전이 더 일찍 관측되었습니다. Ki=0.3에서도 양쪽 출발 지연과 속도 변동이 남았습니다.
- Ki=0.3의 -0.3rad/s 시험에서 왼쪽 최대 관측 속도는 72.90mm/s, 최대 듀티는 49.35%였습니다. 후반 평균만으로 과도 응답까지 안정적이라고 판단하지 않습니다.
- 각 조건 1회씩이며 시험 순서·바닥 위치·차체 자세·배터리 상태를 통제하지 않았습니다. 회전용 최종 이득 확정과 직진 성능 검증은 하지 않았습니다.
- 종료 후 차체 명령, 양쪽 목표·측정 속도·적분·듀티·CCR이 모두 0인 것을 확인했습니다. 양쪽 Kp=0.1, Ki=0.1로 복구하고 읽기 확인했습니다.
- 원시 표본과 구간별 요약은 이 폴더의 `ki_*.json`, 전체 비교와 복구 확인은 `comparison.json`에 있습니다.
