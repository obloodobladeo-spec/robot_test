## 확인 범위

- 전후진 모두 엔코더 속도는 같은 부호로 들어왔으며 마지막 2초 평균의 좌우 차이는 약 1~2mm/s였습니다.
- 전진은 평균이 목표보다 약 4~6mm/s 높았습니다. 후진에는 순간 속도 변동이 남아 왼쪽 -65.89~-36.45, 오른쪽 -67.01~-40.48mm/s가 관측됐습니다.
- 차체의 실제 이동 거리·직진 궤적·후륜 헛돎·앞쪽 옆 미끄러짐은 엔코더만으로 확인하지 못했습니다. 이 값만으로 접지력이 충분하다거나 슬립이 없다고 판정하지 않습니다.
- 각 단계 종료 때 차체 전진·회전 명령과 두 모터의 목표·적용 목표·실제 속도·적분·듀티·CCR이 모두 0인 것을 확인했습니다.
