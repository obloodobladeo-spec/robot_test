# 회전 Ki 비교 재측정

## 조건

- Kp=0.1 유지, Ki=0.1·0.2·0.3 순서로 양방향 각 20초 시험했습니다. 회전 ±0.3rad/s, 전진 0, 좌우 목표 크기 34.5mm/s입니다.
- 윤거 230mm, 가속도 제한 100mm/s², 듀티 상한 50%입니다. 앞 보조 바퀴 테이프·추가 하중은 이전 사용자 보고를 기준으로 하며 질량·위치와 시험 간 동일성은 별도 계측하지 않았습니다.
- 보드와 ELF 일치 확인 후 RAM 이득만 변경하고 읽기 확인했습니다. 펌웨어 파일 수정·다운로드는 하지 않았습니다.
- [직전 시험](../033054_ki_sweep/README.md)과 같은 명령 순서를 반복했습니다. 바닥 위치·배터리 전압 등은 통제하지 않았습니다.

## 해석과 종료

- Ki가 커질수록 지속 회전 관측까지의 지연이 줄어드는 경향이 재현됐습니다. Ki=0.3에서는 두 방향 모두 양쪽이 약 5초에 해당 기준에 도달했습니다.
- 이번 Ki=0.3의 후반 평균은 목표에 가까웠으나 -0.3 방향 왼쪽 표준편차 14.66mm/s 등 변동이 남았습니다. Ki를 높이면 항상 흔들림까지 줄어든다는 결론은 내리지 않습니다.
- 재측정에서도 정지 상태부터 약 5초 지연이 남습니다. 최종 회전용 이득이나 직진용 이득으로 확정하지 않았습니다.
- 각 시험 정지 확인 후 다음 시험을 진행했습니다. 전체 종료 후 차체 명령, 양쪽 목표·실제 속도·적분·듀티·CCR 모두 0, 양쪽 Kp=0.1·Ki=0.1 복구를 읽어서 확인했습니다.
- 원시 표본은 `ki_*.json`, 비교와 종료 확인은 `comparison.json`에 있습니다.
