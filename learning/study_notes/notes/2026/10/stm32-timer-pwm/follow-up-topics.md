# STM32 별도 복습 항목

사용자 요청: 질문에서 나온 보충 개념을 정규 실습 단계로 늘리지 않고 이 문서에 기록한다. 예정된 입력 캡처 → 엔코더 → 속도 제어 → UART/ROS2 흐름을 유지한다.

## 필요할 때 별도로 복습

- `volatile`과 `static`: 접근 최적화, 저장 수명, 이름의 범위 차이.
- 임계 구역과 PRIMASK: read-modify-write 충돌, 기존 인터럽트 마스크 저장·복원, 차단 시간을 짧게 유지하는 이유.
- 요청 플래그와 카운터: 요청 합치기, 누적, 오버플로, 과부하와 지연된 출력의 차이.
- 타이머 동기화: 같은 클럭 주파수와 같은 시작 위상은 다름. 필요하면 master/slave 연동 학습.
- 입력 캡처 심화: 여러 번의 카운터 넘침, 누락된 에지·오버캡처, 입력 필터, 듀티 측정, DMA. 첫 실습에서는 1kHz 신호의 연속 상승 에지 사이 간격만 측정.

## 현재 실습 범위

- TIM2 PA5에서 1kHz·50% PWM 고정 출력.
- PA5와 PA6를 점퍼로 연결하고 TIM3 CH1에서 상승 에지를 캡처.
- TIM3 카운트 간격 1μs, ARR 65535로 두 캡처 값의 차이를 측정.
- 기존 TIM3 주기 갱신·밝기 요청 코드는 이번 실습에서 사용하지 않음.
- 계획 기록이며, 이 문서 작성으로 보드 실행이나 펌웨어 수정을 수행하지 않음.
