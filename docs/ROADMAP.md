# 구현 순서와 완료 기준

기준일: 2026-10-23. 전체 목표는 **STM32에서 안정적으로 바퀴를 제어하고, Jetson에서 센서를 통합하여 로봇을 주행시키는 것**입니다. 현재 학습 코드는 유지하면서 단계마다 실행 결과를 확인합니다.

구성 기준은 [ARCHITECTURE.md](ARCHITECTURE.md)를 따릅니다. 아래 미완료 단계는 계획이며 아직 실행 가능한 통합 기능이 아닙니다.

## 현재 위치

- 학습 완료·실기 확인: 엔코더, PWM/DIR, PI와 anti-windup, 가감속 제한, 모터 코드 분리, 차동구동 속도 변환, 바퀴 오도메트리, UART 송수신, 유효 명령 판별, 통신 단절 정지.
- PC 시리얼로 주기적 명령 전송 및 타임아웃 정지 시험은 수행했습니다. 이를 재사용 가능한 실행 도구로 정리하는 것이 다음 단계입니다.
- LDS-03은 WSL ROS 2에서 드라이버 정상 실행을 확인했습니다. C1의 ROS 2 연결과 Jetson 통합을 확인한 것은 아닙니다.
- 이 저장소의 기존 독립 데모와 현재 학습 펌웨어는 별도이며 통신 규약 통합이 필요합니다.

## 단계별 계획

| 순서 | 핵심 학습/구현 | 완료 기준 |
|---|---|---|
| 1 | PC 명령 전송 도구: 100ms 주기로 명령 전송, 종료 시 정지 | 목표 속도 변경 반영, 송신 종료 후 STM32 정지, 잘못된 명령 거부 |
| 2 | Jetson USB 연결과 `/cmd_vel` 브리지 | teleop의 m/s·rad/s를 STM32 단위로 변환, 두 방향 저속 주행, 오래된 명령·USB 단절 시 정지 |
| 3 | 피드백 규약 정리 | 좌우 속도와 x/y/yaw, 순번·시간 정보, 충분한 정밀도, 100ms 보고, 양쪽 파서 일치 |
| 4 | ROS 바퀴 오도메트리와 로봇 모델 | `/wheel/odometry`, URDF, 장착 위치 TF, RViz에서 이동·회전 방향 확인 |
| 5 | C1과 기본 bringup | `/scan` 주기·거리 확인, `laser` TF 정렬, 브리지·모델·라이다를 launch로 실행 |
| 6 | 외장 IMU 선정·연결·보정 | 전압/인터페이스 확인, 정지 편향·회전 부호·축 방향 확인, `/imu/data`와 시간 정보 확인 |
| 7 | 바퀴 + IMU EKF | `/odometry/filtered`, 단일 `odom → base_link`, 정지·직진·양방향 회전 로그 비교 |
| 8 | 실제 바닥 주행 보정 | 최종 바퀴 간격·회전당 카운트 재확인, 직진 거리·회전각 오차 측정, 적재 상태 시험 |
| 9 | SLAM 지도 작성 | `/scan`과 TF 연결, 지도 저장, 반복 주행 시 지도 형상 확인 |
| 10 | 위치 추정과 Nav2 | 지도 위치 추정, 제한 속도 내 목표점 주행, 장애물·명령 단절 정지 확인 |

DMA 등 별도 기능을 학습 과정에 추가하지 않습니다. 필요성이 확인되면 미뤄 둔 개선 항목으로 기록하고 현재 단계부터 마칩니다.

## 단계별 실행 원칙

1. 빌드와 통신 형식을 먼저 확인합니다.
2. 바퀴를 띄워 방향·속도·정지 동작을 확인합니다.
3. 바닥에서는 이동 공간에 맞춰 저속과 시험 시간을 설정합니다.
4. 목표/실제 속도, 듀티, 좌우 엔코더, 통신 상태를 함께 기록합니다.
5. 결과가 맞은 뒤 다음 단계를 시작합니다. 미검증 상태를 완료로 표시하지 않습니다.

## 통합 전에 맞출 사항

- **프로토콜:** 학습용 ASCII와 기존 데모의 CRC 규약 중 통합 규약을 확정하고 펌웨어·브리지를 동시에 맞춥니다.
- **주기:** 제어/피드백 우선 100ms, 명령 송신 100ms를 출발점으로 실제 지연·주행 결과를 확인합니다. 이 값이 최종 최적값이라는 뜻은 아닙니다.
- **속도 제한:** 바퀴 ±200mm/s, 듀티 50% 상한 유지. teleop 각속도는 실제 회전 결과로 정합니다.
- **명령 수명:** ROS 입력 타임아웃과 STM32 500ms 타임아웃을 각각 시험합니다. ROS 입력이 끊기면 이전 속도를 계속 송신하지 않습니다.
- **좌표:** 구동축 중간점, 좌우 모터와 엔코더 부호, 전방 +X·좌측 +Y·반시계 +yaw를 일치시킵니다.
- **시간:** 센서 측정 시각과 ROS 수신 시각의 관계를 정하고, 시간 지연과 공분산을 측정 없이 임의의 확정값으로 두지 않습니다.
- **IMU:** 모델이 정해지기 전에는 전원 핀이나 I2C/SPI/UART 핀을 확정하지 않습니다.

## 기록할 결과

각 단계에서 날짜, 사용 펌웨어/커밋, 장착·적재 상태, 설정값, 실제 측정값, 미확인 항목을 남깁니다. 기존 `VALIDATION.md`의 독립 데모 결과와 앞으로의 통합 실기 결과를 구분합니다.

이 계획을 올린 시점에는 학습 워크스페이스, 기존 펌웨어, Jetson 실행 코드와 장치 설정을 변경하지 않았습니다. 통합 launch·IMU 드라이버 설정·EKF 설정은 후속 단계에서 구현합니다.
